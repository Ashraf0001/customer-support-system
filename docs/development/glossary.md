### Glossary (Quick Reference)

- FastAPI: Python web framework for APIs
- Celery: background task queue
- Redis: broker/result backend for Celery
- SQLAlchemy: ORM for database models and queries
- Alembic: migration tool for SQLAlchemy
- Pydantic: data validation models
- Ollama: local LLM server (no cloud dependency)
- Uvicorn: ASGI server for FastAPI
- Repository Pattern: abstraction layer for DB CRUD
- Workflow/Node: pipeline stages executed in sequence
- TaskContext: shared state passed between nodes
